### 参考一：CSDN年度报告

今年（2020年）2月份，CSDN公布了2019-2020 年中国开发者大调查，其中显示了当前国内IT行业的从业情况：

- 30 岁以下开发者人数占比超八成；
- 全国有 19.6% 开发者月薪超过 1.7 万元；
- 六成开发者在使用 Java 语言；
- 近五成开发者近期最想学 Python 语言。

其中，IT行业的开发语言的使用情况为：

- Java占据最常用的语言、最想学的语言榜首；
- Java、JavaScript、SQL、C、Python分别占据开发者最常用语言前五；
- Java、Python、JavaScript、SQL、C分别为开发者最想学的语言前五。

### 参考二：PYPL 月度排名

PYPL（**PopularitY of Programming Language**，编程语言流行指数）是非常流行的参考指标，其榜单数据的排名是根据榜单对象在 Google 上相关的搜索频率进行统计排名，原始数据来自 Google Trends，也就是说某项语言在 Google 上搜索频率越高，表示它越受欢迎。

PYPL已发布了今年5月的榜单，根据榜单对象在 Google 上相关的搜索频率进行统计排名。

排名前五的分别是：Python, Java, JavaScript, C# 和 PHP。

跟国内统计数据不太一样。Python不仅在份额上遥遥领先，位列第一，与去年同期相比的增长幅度也是最大的。

在了解国内外编程语言的应用趋势后，再来看下**企业端**的应用。

各大厂使用的编程语言并不只有一种，既然冲着“好找工作”的目标去，我们还是将注意力放在各厂的主要开发语言上。

- 猫厂和狗厂：Java语言；
- 百度：Python和PHP；
- 鹅厂和猪厂：C++；
- 豆瓣和知乎：Python；
- 宇宙条：Python和Go。

很显然，C/C++是王者语言，如果你准备在软件工程领域深耕下去，建议在大学期间，认真对待C语言课程。对性能要求高的应用，比如，游戏开发，服务器开发，都需要用到C++这样执行速度飞快的语言。一般而言，将C/C++学好，学别的语言就很快。

Python语言的上升趋势不可谓不迅猛，因其上手容易、语法强大、功能简单受到了很多人的喜欢，被称为胶水语言。主要应用领域：人工智能、科学运算、数据分析、运维、web开发、爬虫、游戏开发、机器学习等。目前，国外像谷歌、Youtube，国内像网易、腾讯、搜狐、金山、知乎、豆瓣，都有应用Python。

Java算是常年行走江湖的老大哥了，使用时间长，应用广泛，生态好，协作性强，很多企业级应用都是用Java开发的，但是它并不是容易学的语言，想要有更深入的学习，还需要时间的积累。

Go语言是谷歌推出的编程语言，可以在不损失应用程序性能的情况下降低代码的复杂性，易学、精简，在后端的应用场景下表现得都还不错。目前，Google、Facebook、今日头条、京东、小米等大的互联网公司都有应用。

PHP？就不用说了吧。PHP是世界上最好的语言。

### 《C Primer Plus（第6版）中文版》

作者：[美] Stephen Prata  译者：姜佑

从1984年至今，《C Primer Plus》已经升级到了第6版，作者保持初心，一直致力于编写一本**指导性强、条理清晰、有用**的C语言教程。

本书全面讲述了  C 语言编程的相关概念和知识，涵盖了 C 编程语言最近的变动发展以及 C11  标准，在每个知识点后面都会附带程序实例，供初学者手动实操，提升编程水平。更有趣的是，作者不仅阐述了语法中正确的形式，同时也指出错误的代码出现的问题，从正反两面帮助读者建立正确的概念。

### **《**C 和指针**》**

作者：[美] Kenneth A.Reek  译者：徐波

“不会用指针就不会 C 语言”，这是程序员间互相流传的信条，他们认为正是指针使得 C 语言如此强大，所以想要掌握 C 语言的精髓，首先要精通指针！

全书共18章，覆盖了数据、语句、操作符和表达式、指针、函数、数组、字符串、结构和联合等几乎所有重要的C编程话题。书中给出了很多编程技巧和提示，每章后面有针对性很强的练习，帮助程序员把指针的强大功能融入到自己的程序中去。

### 《C++ Primer Plus 第6版 中文版》

作者：[美]Stephen Prata  译者：张海龙，袁国忠

本书可以说是一本面向从未学习过C语言甚至是从未学习过编程的人的入门书籍，是首本支持C++11新标准的程序设计图书，是经久不衰的C++畅销经典教程。

它的首章从基础内容讲起，先介绍了传统编程的规则，后面才着重讲解有关面向对象——C++的精髓之一——的有关内容。整个书的结构安排较为合理，难度爬升较慢。如果你是一个从未学过C语言（或者压根没学会C）的读者，那么，这本书很适合你。

### 《Python编程：从入门到实践》

作者：[美]Eric Matthes  译者：袁国忠

这是小白入门的必备书。共分为入门和实践两个部分：第一部分介绍了Python编程的基本概念，包括matplotlib、NumPy和Pygal等强大的Python库和工具介绍，以及列表、字典、if语句、类、文件与异常、代码测试等内容；第二部分将理论付诸于实践。帮助读者理解Python编程的概念及用途。使用Python  2或Python 3的读者都可以利用这本书来学习。

这本书的特别之处是，它从基本概念到完整项目开发，进行了基础的介绍，同时还附赠源代码文件+丰富的教学视频，“阅读障碍者”可以先看教学视频，另外，B站也有视频教程可以参考。

### 《笨办法学Python 3》

作者：[美]泽德 A. 肖  译者：王巍巍

这也是一本入门级的书，但和第一本不同的是，它从习题切入，更具实践性。适合对计算机了解不多，没有学过编程，但对编程感兴趣的读者学习使用。

书中以习题的方式引导读者一步一步学习编程，从简单的打印一直讲到完整项目的实现，让初学者从基础的编程技术入手，最终体验到软件开发的基本过程。

### 《笨办法学Python 3 进阶篇》

作者：[美] 泽德·A. 肖（Zed A. Shaw）  译者：王巍巍

这本书是《“笨办法”学Python 3》的进阶篇，《“笨办法”学Python 3》介绍了用Python 3编程的基础知识，而本书则通过52个精心设计的习题帮助读者超越基础，提升水平。

这52个习题大部分都结合实际演示，并配有附加挑战，每个习题都可以帮读者掌握一项关键的实践技能，旨在帮助读者从单纯地编写能运行的代码跨越到编写能解决实际问题的高质量Python代码，成为一名高阶的Python程序员。

### 《Spring实战 第5版》

作者：[美] 克雷格·沃斯（Craig Walls） 译者：张卫滨

这本书是Pivotal首席软件工程师的力作，是一本经典而实用的畅销Spring 学习指南。 

第5版中，涵盖了Spring 5.0 和Spring Boot 2.0 里程碑式的更新。既适合刚开始学习Spring Boot 和Spring 框架的Java 开发人员快速上手，也适合经验丰富的Spring 开发人员学习Spring 的新特性，尤其适用于企业级Java 开发人员。

### 《Go语言趣学指南》

作者：[加]Nathan Youngman，[英] Roger Peppé   译者：黄健宏

本书循序渐进地介绍了使用Go语言必需的基础知识，书中的内容首先从变量、循环、分支、类型等基础知识开始，逐渐进阶至函数、方法、收集器和结构，最后再深入到指针、错误处理和并发等高级特性，并且每个单元都包含相应的章节和单元测试。

### 《Go语言实战》

作者：[美]William Kennedy，Brian Ketelsen，Erik St. Martin  译者：李兆海

Go语言结合了底层系统语言的能力以及现代语言的高级特性，旨在降低构建简单、可靠、高效软件的门槛。本书向读者提供一个专注、全面且符合语言习惯的视角，同时关注语言的规范和实现，涉及的内容包括语法、类型系统、并发、管道、测试，以及其他一些主题。本书适合有一定其他编程语言经验，想要开始学习Go 语言或者更深入了解Go 语言及其内部机制的中级开发者。
